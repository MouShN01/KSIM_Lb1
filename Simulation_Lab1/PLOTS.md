# Графіки у VS Code

Графіки створені за допомогою Python і Matplotlib. Для їх редагування у VS Code достатньо встановленого Python та розширення Python від Microsoft.

1. Відкрий папку `Simulation_Lab1` у VS Code.
2. Вибери потрібне середовище Python через команду `Python: Select Interpreter`.
3. У терміналі цього середовища, у папці `Simulation_Lab1`, встанови бібліотеку:

```sh
python -m pip install -r requirements.txt
```

4. Перебудуй графіки:

```sh
python plots.py
```

Якщо у твоїй системі Python запускається командою `python3`, використовуй її замість `python`.

- `chart-data.json` містить фактичні початкові та кінцеві запаси їжі всіх прогонів трьох експериментів. Повторне використання базової серії відповідає опису у звіті.
- `plots.py` обчислює індивідуальні відсотки та середні і зберігає три PNG у папці `figures`.
- Межі вертикальної шкали задаються через `ax.set_ylim(...)`, поділки - через `ax.set_yticks(...)`.
- Для дифузії та випаровування нижня межа становить 70%, для популяції - 25%. Усі індивідуальні результати залишаються видимими.
- Сірі точки показують окремі прогони, кольорова лінія - середні, вертикальні відрізки - мінімум і максимум. Значення повторів, які збігаються, накладаються.
